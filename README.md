# tiburon-kilat

Berita teknologi penting dikirim ke Telegram begitu terbit. Jalan di GitHub Actions tiap 5 menit, jadi tidak butuh komputer pribadi yang menyala.

Sumber: TechCrunch, The Verge, Wired, Ars Technica, Engadget, VentureBeat, MIT Technology Review, Rest of World, Sifted, dan Hacker News.

Yang dikirim hanya berita yang judulnya menyebut perusahaan atau produk besar sekaligus peristiwa besar (rilis, akuisisi, pendanaan, kebocoran, gangguan, gugatan), atau cerita Hacker News di atas 300 poin. Maksimal empat berita per kiriman, judul diterjemahkan ke bahasa Indonesia. Pukul 00.00 sampai 06.00 WIB tidak ada kiriman.

Secret yang dibutuhkan: `TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID`, dan opsional `GEMINI_API_KEY`.
